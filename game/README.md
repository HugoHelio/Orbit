# Le jeu (prototype web)

Le code du prototype web de Helioso Orbit, écrit avec Claude Code. Les règles techniques sont dans `CLAUDE.md` et dans la section 12 du GDD.

| Dossier | Contenu | État |
|---|---|---|
| `plateau/` | La démo animée du plateau (`docs/jeu/spec-prototype-plateau.md`). Elle s'ouvre en double-cliquant sur `index.html`, sans serveur. | En cours : étape 1 faite, étape 2 à moitié |
| `spaceplan-builds/` | Le code repris de SpacePlan (prototype, PoC, alpha, bêta), joué à chaque release (`docs/jeu/builds-spaceplan.md`) | Repris tel quel, à adapter en S2 |

Le moteur de règles viendra après la démo, si elle convainc (sprint S1, janvier 2027). Il appellera les mêmes fonctions d'affichage que le script de la démo.
